# Instructions for creating a new release

**Note:** DOIs do not need to be updated as they use the 'overall' DOI for this project, 
not the version specific doi.

- Make edits
- Update NEWS.md with what changed, date, and new version
- Update README.md citation at the bottom: New authors, Year, new version.
- Update the index.qmd citation at the bottom: New authors, Year, new version.
- Create a new release, tag is `vX.X` for the new version, text is header 
  `## Month day(th), Year` followed by the text from NEWS.md
- Consider writing Blog post to advertise/explain the update
